# **App Name**: SwimWise

## Core Features:

- User Profile Management: Create and manage user profiles with fields for name, date of birth, email, password, and personal notes.
- Competition Time Tracking: Store and visualize competition times for each athlete.
- Workout Management: Create, store, and manage workouts with tables for estimated and actual times.
- Performance Analysis: Analyze performance with charts comparing times vs. dates for different events.
- Most Frequent Events: Calculate and display the most frequently competed events.
- Workout Suggestions (AI): Suggest workouts based on past performance and goals, by using an AI tool.
- Dark/Light Mode Toggle: Allow users to switch between dark and light interface modes.

## Style Guidelines:

- Primary color: Dark blue (#181B52) to provide a sense of focus and professionalism. This color will set the overall tone.
- Background color: Light gray (#D3D4EB) for a clean, readable surface that complements the dark blue without overpowering it.
- Accent color: Medium blue (#424685) to highlight key interactive elements and important information within the app.
- Headline font: 'Belleza' (sans-serif) for an artistic and slightly high-fashion feel. Body font: 'Alegreya' (serif), when a longer body of text is present. 
- Use minimalist icons to represent different swimming strokes, workout types, and data visualizations.
- Employ a tab-based navigation for main sections (Dashboard, Workouts, Competitions, Profile) to provide intuitive access.
- Use subtle transitions when navigating between screens and displaying data to provide a smooth user experience.
